# THE REGISTER OF EXEMPTED DESIGN CITATIONS - the only thing that grants
# an exemption. Three columns, TAB separated:
#
#     <tracked path>  <TAB>  <start>-<end>  <TAB>  <the reason>
#
# A citation is exempt from the two wired citation gates and from
# repoint-design-citations.py if AND ONLY IF its line carries the
# REPOINT-EXEMPT marker AND the (path, address) pair appears below with a
# non-blank reason. The marker alone grants nothing - that is #142, and
# it is why 36 lines that merely NAMED the marker were silently exempt
# from two wired gates while exempting nothing.
#
# THIS FILE IS `.txt` ON PURPOSE AND MUST NOT BECOME .py, .json, .md OR
# .yaml. Every one of those suffixes IS scanned by one of the gates this
# register feeds - check-design-citations.py reads .py .toml .md .yml
# .yaml .sh, check-design-citation-shape.py reads .py .sh - so a register
# written in any of them would be scanned by the gate it governs, and
# would have to exempt itself. That self-reference IS the defect this
# file exists to close. `.txt` is in neither suffix set and is on
# scripts/check-committed-file-types.py's allowlist. Converting it is not
# a tidy-up; it reopens the hole.
#
# The key carries NO LINE NUMBER, per #6: a path:line key rots on the
# first edit above the line and then silently re-exempts whatever moved
# into the slot. The address is normalised `<start>-<end>` even when the
# citation is written as a single line.
#
# ADDING A ROW IS THE POINT OF FRICTION. It is a visible diff in a file
# whose length is reported on every run. A citation that cannot be
# defended in one sentence here does not belong in the tree.
