## The credentialed arm, and the trap that was disarmed for you

**You add the FIRST credentialed arm in this repository**, and it is the first test file whose tests
are all marker-excluded.

**Collision 11 was your trap and it was closed before you were dispatched** (`1e67f9c`). The
collection guard used to run collection through the `-m "not credentialed and not network"`

that claimed the opposite is rewritten, and a regression test manufactures the shape rather than

**What you must NOT do**, because both green the guard by hiding the subtree it exists to protect:

- do **not** add `credentialed` to `_SKIP_DIRS`;
- do **not** put the arm in a file that also holds an unmarked test.

**If you change that guard at all, you owe its third arm** - a genuine orphan outside `testpaths`
must still fail after your change.

**AND THE RULE THAT HAS NO GATE.** `tests/credentialed/README.md` forbids module-scope credential
reads. **Collection IMPORTS every module in `testpaths`**, so a credential read at module scope
executes during collection - on every offline run that deliberately deselects those tests, and in
CI. Measured and settled: this is **not** caused by dropping `-m`; a module planted under
`tests/credentialed/` is imported with the selector and without it, identically. **Put credential
reads inside fixtures or test bodies, never at module scope**, and consider leaving behind the gate
nobody has written.
