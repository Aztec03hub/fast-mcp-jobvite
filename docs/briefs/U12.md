## The one arm that carries a High, and the shape it must have

**C5-I1**: the `jobFeed` URL must never reach a log record whole, with `sc=` redacted. This is the
one endpoint that **structurally requires the secret in the query string** - `DESIGN.md:315-318`.

**ASSERT IT AGAINST A LOG STREAM PROVEN NON-EMPTY BY THE SAME CALL**, exactly as U3's §8 #2 does:
the call emits a record carrying the request's non-secret attributes, **and** the `sc=` value is
absent from *that record*.

> **Against a logger emitting nothing, the absence alone passes - and this arm carries a High.**

The round-trip arm does NOT close it: it proves the tool returns data, not that the logger emitted
anything. The plan calls this *"Q6's shape one unit later"* and names fix-one-miss-the-sibling as a
failure it has already recorded three times. **Do not let your High rest on an absence.**
